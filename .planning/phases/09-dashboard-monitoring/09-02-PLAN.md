    Create the Vite + React project manually (do NOT use `npm create vite` -- write files directly to avoid interactive prompts):

    **package.json:** React 19, react-dom 19, lightweight-charts ^5.1, react-gauge-component ^2, plus devDeps: @vitejs/plugin-react ^4, @types/react ^19, @types/react-dom ^19, typescript ^5, vite ^6.

    **tsconfig.json:** target ESNext, module ESNext, moduleResolution bundler, jsx react-jsx, strict true, include ["src"]. Isolated from root tsconfig.

    **vite.config.ts:** Plugin react(), proxy /api to http://localhost:3001, proxy /ws to ws://localhost:3001 with ws:true, build.outDir = '../../dist/dashboard'.

    **index.html:** Standard Vite HTML with `<div id="root">` and `<script type="module" src="/src/main.tsx">`.

    **src/main.tsx:** ReactDOM.createRoot, renders `<App />`.

    **src/types.ts:** Mirror server WsMessage and WsCommand types. Define frontend data interfaces: SessionData, TradeData, EquityPoint, PositionData, RiskStatus, StrategyInfo. All financial values as strings.

    **src/styles/index.css:**
    - Dark theme: body background #0f0f1a, color #d1d5db, font-family system-ui
    - Monospace for numbers: .mono { font-family: 'JetBrains Mono', 'Fira Code', monospace }
    - Flash animations: `.flash-up { animation: flash-green 0.5s ease-out }`, `.flash-down { animation: flash-red 0.5s ease-out }`
    - @keyframes flash-green: 0% bg rgba(34,197,94,0.3), 100% transparent
    - @keyframes flash-red: 0% bg rgba(239,68,68,0.3), 100% transparent
    - Responsive grid layout: `.dashboard-grid { display: grid; grid-template-columns: 3fr 2fr; gap: 1rem; padding: 1rem }`
    - Panel styling: `.panel { background: #1a1a2e; border-radius: 8px; padding: 1rem; border: 1px solid #2a2a3e }`
    - Table styling: dark rows, hover highlight, alternating stripes
    - Per locked decision: green (#22c55e) for profit/up, red (#ef4444) for loss/down
    - Scrollbar styling for dark theme

    **src/hooks/useWebSocket.ts:**
    - Export `useWebSocket(url: string, onMessage: (type: string, payload: unknown) => void)`
    - Returns `{ status: 'connecting' | 'connected' | 'disconnected', send: (cmd: unknown) => void }`
    - Auto-reconnect with exponential backoff: base 1s, max 30s, with jitter (delay * 0.2 * Math.random())
    - Reset retry counter on successful connection
    - Cleanup on unmount (close WebSocket, cancel reconnect timer)

    **src/hooks/useFlash.ts:**
    - Export `useFlash(value: number | string, duration?: number)` returning 'up' | 'down' | null
    - Compares current value to previous via useRef
    - Sets flash direction, clears after duration (default 500ms)
    - Per locked decision: subtle flash/color pulse on changed values (trading terminal style)

    **src/components/Header.tsx:**
    - Sticky top bar with dark background (#0a0a16)
    - Left: connection status dot (12px circle, green #22c55e when connected, red #ef4444 when disconnected, yellow #eab308 when connecting) -- per locked decision
    - Center: "Trading Dashboard" title
    - Right: placeholder slot for kill switch button (implemented in 09-03)
    - Per locked decision: connection dot with auto-reconnect visual feedback

    **src/App.tsx:**
    - Single-page layout (per research recommendation, no tabs)
    - Import and render Header at top
    - Grid layout: left column (60%) for PriceChart + EquityCurve, right column (40%) for placeholder panels (risk, strategies, positions)
    - Bottom full-width: TradeHistory
    - Manage WS connection via useWebSocket hook
    - On mount: fetch initial data from /api/sessions (latest running or most recent), /api/sessions/:id/equity, /api/sessions/:id/trades, /api/positions
    - Dispatch WS messages to update component state

    Then run `cd src/dashboard/ui && npm install` to install frontend dependencies.
