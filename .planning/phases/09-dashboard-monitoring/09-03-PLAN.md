  <action>
    **DrawdownGauge.tsx:**
    - Props: `{ currentDrawdownPct: number; maxDrawdownPct: number }`
    - Per locked decision: semicircular gauge meter with green-yellow-red zones
    - Per locked decision: gauge color zones are config-driven -- thresholds derived from actual risk config
    - Use react-gauge-component with type="semicircle"
    - Color zones calculated from maxDrawdownPct:
      - Green: 0 to 50% of max
      - Yellow: 50% to 80% of max
      - Red: 80% to 100% of max
      - Dark red: beyond max (20% headroom)
    - Value label formatted as percentage with 1 decimal: `${v.toFixed(1)}%`
    - Title label: "Drawdown"
    - Gauge arc width ~0.2, pointer visible

    **ExposureGauge.tsx:**
    - Props: `{ currentExposurePct: number; maxExposurePct: number }`
    - Same pattern as DrawdownGauge but for exposure
    - Per locked decision: config-driven color zones from risk config max exposure
    - Color zones: Green 0-50%, Yellow 50-80%, Red 80-100%, Dark red beyond
    - Title label: "Exposure"

    **CircuitBreakerBanner.tsx:**
    - Props: `{ isActive: boolean; message: string; triggeredAt?: number; isMuted: boolean }`
    - Per locked decision: red banner across the top when circuit breaker triggers
    - Per locked decision: audible alert sound when circuit breaker fires
    - Banner: full-width, red background (#dc2626), white text, animated slide-down entrance
    - Display: breaker type, trigger time, message
    - Sound: generate a short alert beep using Web Audio API (OscillatorNode, 800Hz sine wave, 200ms duration, with gain envelope). Do NOT use an audio file -- Web Audio API is more reliable and avoids asset loading issues. Play sound on isActive transition from false to true (use useEffect + useRef to track previous state). Skip sound if isMuted is true.
    - Dismissible: small X button to hide banner (but keep state)

    **RiskPanel.tsx:**
    - Props: `{ riskStatus: RiskStatus; riskConfig: { maxDrawdown: number; maxExposure: number }; circuitBreakerEvents: Array<{ timestamp: number; type: string; resolution: string }> }`
    - Render DrawdownGauge and ExposureGauge side by side (flexbox row)
    - Per locked decision: circuit breaker event log visible in risk panel -- list of recent triggers with timestamp, type, and resolution
    - Below gauges: "Circuit Breaker Log" section
    - Table: Timestamp (formatted), Type, Resolution columns
    - Show last 20 events, most recent first
    - Empty state: "No circuit breaker events"

    **Update App.tsx:**
    - Add riskStatus state, fetched from `GET /api/risk` on mount
    - Add circuitBreakerEvents state, fetched from `GET /api/risk/events` on mount
    - Wire WS messages:
      - 'riskUpdate' -> update riskStatus (drawdown, exposure values)
      - 'circuitBreaker' -> set banner active, add to events list, play alert sound
    - Render CircuitBreakerBanner below Header (conditionally, when active)
    - Render RiskPanel in right column (above StrategyControls)
    - Pass isMuted from Header mute toggle state down to CircuitBreakerBanner

    **Update styles/index.css:**
    - Circuit breaker banner: `.cb-banner { background: #dc2626; color: white; padding: 0.75rem 1rem; animation: slideDown 0.3s ease-out; }`
    - @keyframes slideDown: from { transform: translateY(-100%); opacity: 0 } to { transform: translateY(0); opacity: 1 }
    - Gauge container styling for side-by-side layout
    - Event log table styling (compact, scrollable if many events)
