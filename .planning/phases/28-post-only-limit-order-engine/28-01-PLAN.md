**order-engine.ts — NEW FILE:**

Implement PerpOrderEngine as an EventEmitter. Constructor accepts:
```typescript
{ intxClient: IntxClient; stateStore: PerpStateStore; config: FcmConfig }
```

Implement submitEntryOrder(params: { instrument: string; direction: PerpDirection; size: string; midPrice: string; atr: string; getMidPrice: () => Promise<string> }): Promise<PerpSession>

The cancel-reprice loop logic:
1. Generate clientOrderId = crypto.randomUUID()
2. Build PerpOrder with purpose='ENTRY', status='PENDING', limitPrice=midPrice
3. Persist (persistOrder) BEFORE API call
4. Call intxClient.placeOrder({ orderType: 'LIMIT', postOnly: true, limitPrice: midPrice, ... })
   — postOnly flows through PlaceOrderParams.postOnly (added to types.ts in Task 1) into intx-client.ts placeOrder() which sets `post_only: params.postOnly ?? false` in the limit_limit_gtc block
5. If API throws with failure_reason in NON_RETRYABLE set → mark order FAILED, throw OrderError(isRetryable: false)
6. If API returns success=false (post-only rejection = taker-would-fill) → mark order CANCELLED, emit 'repriced', increment attempt counter
7. If attempt >= config.maxRepriceAttempts or elapsed >= config.entryOrderTimeoutMs → throw OrderError('max reprice attempts exceeded')
8. Get new midPrice via getMidPrice() callback, sleep 500ms, loop
9. On API success (orderId returned): update order status=OPEN, exchangeOrderId=orderId
10. Wait for fill: listen for 'orderFill' event matching clientOrderId OR poll getOrder() after 30s timeout
11. On fill: update order status=FILLED, avgFillPrice, fee; create PerpSession via stateStore.createSession(); emit 'entryFilled'; return session

Also implement cancelAllOpenOrders(sessionId: string): Promise<void>:
- Call stateStore.getOpenOrdersBySession(sessionId)
- Collect exchangeOrderIds (skip those without one)
- Call intxClient.cancelOrders(orderIds) — this is the public method on IntxClient; never access restClient directly
- Mark each order CANCELLED in DB via persistOrder
- Log at info for success, warn for partial failures (do not throw)
